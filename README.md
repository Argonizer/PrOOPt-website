# PrOOPt Website

The GitHub Pages site for **PrOOPt** — Object-Oriented Prompt Engineering for Java.

Plain black-and-white static HTML. No build step, no framework — open `index.html`
or serve the repository root with any static file server.

## Pages

| Page | Contents |
|---|---|
| `index.html` | Introduction — the what, the why and the how |
| `getting-started.html` | PrOOPt core — requirements, Maven, first `@PromptFunction` |
| `tutorials.html` | PrOOPt core — six structured developer lessons |
| `states-getting-started.html` | PrOOPt States — `@Persona`, `@Trait`, first persona |
| `states-tutorials.html` | PrOOPt States — populations, events, loops, reports |
| `use-cases.html` | Index of six novel use cases |
| `use-cases/*.html` | One detailed page per use case |
